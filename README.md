This study tool was originally created in Python because while taking a linguistics course I realized there were basically no study tools for the IPA chart.
This was unforgivable so I made one and spread it around during office hours to help other students. 
Well that was all fine and dandy but recently I thought, "hmm having to send the repo for this study tool is kinda annoying", so I learned HTML, CSS, and JS to turn it into a website.
With the power of front-end development, now this study tool will be available with a click of a button shortly and no longer requiring cloning a repo (I am so sorry Ling 100).
